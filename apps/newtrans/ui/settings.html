단축키

텍스트를 드래그한 뒤 단축키를 누르면 번역 창이 열립니다. 버튼을 누르고 원하는 키를 누르세요. 수식키를 두 번 빠르게 누르면 "두 번 누르기"로, 최대 3개 키 조합(예: Ctrl+Shift+Z)도 지정할 수 있습니다.

ms (기본 350)

언어

① 원문(언어 1) → ② 번역(언어 2) → ③ 재번역(다시 언어 1). 번역 창에서 언어 1·2를 바꾸면 그 값이 고정됩니다.

원문이 언어 2와 같을 때 사용

번역 서비스

초

API 키

키는 이 컴퓨터의 별도 파일(본인 계정만 읽기 가능)에만 저장되고 다른 곳으로 전송되지 않습니다. 비워 두고 저장하면 기존 키가 유지되고, "삭제"를 누르면 지워집니다.

무료: deepl.com → API 플랜 "DeepL API Free" 가입(월 50만 자) → 계정 → API 키. ":fx"로 끝나는 키가 무료 키입니다.

네이버 클라우드 플랫폼 콘솔 → AI Services → Papago Translation 이용 신청 → Application 등록 후 Client ID/Secret. 유료 서비스이므로 사용량 알림을 설정하세요.

Google 방식을 "Cloud Translation API"로 바꿀 때만 필요합니다. 월 50만 자까지 무료 크레딧이 적용되며, 키를 Cloud Translation API로만 제한하세요.
